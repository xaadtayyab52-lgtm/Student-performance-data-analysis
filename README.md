# Student Performance Data Analysis

A beginner-friendly Data Science project that analyzes student performance using Python.

## Technologies Used

- Python
- Pandas
- Matplotlib

## Project Steps

1. Created a student performance dataset
2. Explored the data using Pandas
3. Generated statistical summaries
4. Created visualizations using Matplotlib
5. Analyzed the relationship between study hours, attendance, and marks
6. Identified key patterns in student performance

## Key Findings

- Students who studied more hours generally achieved higher marks.
- Students with higher attendance generally had better marks.
- The average marks in the dataset were approximately 72.83.
- The highest marks were 92 and the lowest were 55.
